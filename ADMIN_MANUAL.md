# Мануал по админ-панели Regola

## Вход

Админка открывается по адресу из переменной `VITE_ADMIN_PATH`.
Если переменная не задана, путь по умолчанию:

```text
/_secure-admin-7f29A228lswP
```

Для входа нужны три значения из `.env`:

```env
ADMIN_LOGIN=your_login
ADMIN_PASSWORD=your_strong_password
ADMIN_ACCESS_KEY=your_secret_key
```

После изменения `.env` перезапустите сервер.

## Добавить товар

1. Откройте админ-панель.
2. Заполните название, цену и описание.
3. Добавьте одно или несколько фото с устройства или по URL.
4. Первое фото будет главным. Фото можно двигать стрелками и назначать главным.
5. При необходимости добавьте ссылку на видео.
6. Добавьте ссылки Wildberries, Ozon и Яндекс Маркета, если товар там опубликован.
7. Нажмите `Добавить товар`.

## Описание товара

В поле описания можно писать нормальные абзацы и списки.

Пример:

```text
Первый абзац описания.

Второй абзац описания.

- первый пункт
- второй пункт
- третий пункт
```

На сайте текст будет отображаться аккуратно, без склеивания в одну кучу.

## Цена

Цена ставится вручную в поле `Цена, ₽`.

Синхронизации цен с маркетплейсами нет. На карточке товара показывается только цена сайта и ссылки на маркетплейсы.

## Редактировать товар

1. Найдите товар в списке ниже формы.
2. Нажмите `Редактировать`.
3. Измените нужные поля.
4. Нажмите `Сохранить`.

## Удалить товар

1. Найдите товар в списке.
2. Нажмите `Удалить`.
3. Подтвердите удаление.

## Заявки и заказы

Заказы из корзины попадают в раздел `Заявки` в админке.

Статусы:

- `обрабатывается`
- `выполнен`
- `отменён`

Форма `Задать вопрос` сохраняет сообщение в базе. Если на VPS указать `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, вопросы и заказы будут дополнительно приходить в Telegram.

## Если не пускает в админку

1. Проверьте `ADMIN_LOGIN`, `ADMIN_PASSWORD`, `ADMIN_ACCESS_KEY` в `.env`.
2. Перезапустите сервер.
3. Очистите localStorage браузера для домена сайта или нажмите `Выйти`, если старая сессия устарела.
4. Убедитесь, что пароль не короче 12 символов.
